# 🚀 LearnWise AI – Personalized Learning Resource Finder

> Find the **right resource for YOU**, not just the most popular one.

---

## 📌 Problem

Learners often struggle to find the best resources because:
- Too many options (YouTube, blogs, courses).
- No personalization (beginner vs advanced, fast vs slow learners).
- Generic ratings that don’t reflect individual learning styles.

---

## 💡 Solution

**LearnWise AI** is a personalized platform that:
- Recommends resources based on your **learning style**
- Uses **multi-dimensional ratings** (not just 1–5 stars)
- Helps you learn **faster and smarter**

---

## 🎯 Key Features

### 👤 User Profiling
- Select:
  - Skill level (Beginner / Intermediate / Advanced)
  - Learning style (Visual / Practical / Theory)
  - Learning speed (Fast / Slow)

---

### 🔍 Smart Resource Discovery
- Filter by:
  - Topic (React, Node.js, DSA)
  - Learning type
- Personalized results based on your profile

---

### ⭐ Multi-Dimensional Rating System
Each resource is rated based on:
- Beginner Friendliness
- Depth
- Practicality
- Speed suitability
- Overview

---

### 🤖 AI Recommendation Engine
- Suggests best resources based on:
  - User profile
  - Ratings
  - Tags

---

### 🧭 Learning Path Generator (Roadmap)
- Input: “Learn Backend in 2 weeks”
- Output: Structured roadmap + resources

---

## 🏗️ Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Optional AI
- OpenAI API / Custom logic

## 🚀 Getting Started
1. Clone the repo
2. Install dependencies
3. Start the server
4. Open in browser
```bash
git clone
cd learnwise-ai
npm install
npm start
```
